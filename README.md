# Conteúdo

Ferramenta verificadora de log.    
Ferramenta desenvolvida em python3, tenha python3 instalado na máquina.
        
A Ferramenta deve informar:     
* Linhas processadas
* Linhas descartadas
* Top 5 endpoints acessados
* Top 5 tempo de acesso
* Tempo de resposta p95 geral
* Contagem de requisições por classe de status (2xx, 3xx, 4xx, 5xx)

# Como rodar a ferramenta 

rode o comando via terminal   
      
```python3 logstats.py access.log```

# Como rodar os testes

rode o comando via terminal.       
        
```python3 test_logstats.py```
